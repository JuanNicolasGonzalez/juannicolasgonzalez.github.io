# juannicolasgonzalez.github.io

Personal research website of Juan Nicolas Gonzalez, live at https://juannicolasgonzalez.github.io/

The site is a single static page (`index.html`) served by GitHub Pages: profile, research interests and a tabbed publication list (journal, conference and discussion papers).

## Updating

- **Add a publication:** copy an existing `<li>` in the right tab and year in `index.html`. Keep the format `Authors (Year). Title. Journal, Volume(Issue), Pages. DOI link`, with your name in `<strong>`.
- **After any change:** update `<lastmod>` in `sitemap.xml` to the date of the change.
